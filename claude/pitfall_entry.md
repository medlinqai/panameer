# Pitfall entry template

Copy this block into `pitfalls.md` (newest at top) when a new bug class is
identified.

---

## <Short name of the pitfall>

**Symptom:** what it looks like when it bites (the error text / the observed
behavior that misleads).

**Why:** the actual root cause — especially if the symptom points somewhere
misleading.

**Fix / rule:** the concrete action that resolves it, and the standing rule
that prevents it recurring.

**First seen:** YYYY-MM-DD (brief / commit if relevant).
