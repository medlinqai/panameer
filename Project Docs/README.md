# Project Docs

All project documentation, organized by SDLC phase. Mockups and design
artifacts live under **2. Design**.

- **1. Define** — problem, scope, requirements, product principles source material
- **2. Design** — mockups, wireframes, IA, visual direction
- **3. Build** — implementation notes, technical specs feeding briefs
- **4. Test** — test plans, scripts, results
- **5. Deploy** — release notes, environment/runbook docs
- **6. Support** — post-launch issues, ops, maintenance

Durable engineering context (architecture, conventions, decisions, pitfalls)
lives in `../claude/`. This folder is the human-facing SDLC record.
